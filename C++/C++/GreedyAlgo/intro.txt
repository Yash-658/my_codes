CUSTOM COMPARATOR LOGIC:

For:
priority_queue<T, vector<T>, comp>

👉 comp(a, b) = true means:

“a should come after b” (a has lower priority)

FOR MIN-HEAP: 

return a.first > b.first;
Means:
a is “worse” if it is larger
👉 So smaller value gets priority
✔ Top = smallest element
